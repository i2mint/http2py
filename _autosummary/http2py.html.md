# http2py

Tools to make python objects that facade http requests.

### Modules

| [`api_pkg_maker`](http2py.api_pkg_maker.html.md#module-http2py.api_pkg_maker)     | Generate an installable python package from an OpenAPI specification.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|-------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [`authentication`](http2py.authentication.html.md#module-http2py.authentication)   | Resolve credentials and build the auth callables that requests will use.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| [`cli_maker`](http2py.cli_maker.html.md#module-http2py.cli_maker)             | Turn an http-bound python object into a command line interface.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| [`client`](http2py.client.html.md#module-http2py.client)                   | The main entry point: a python object facading an http service.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| [`constants`](http2py.constants.html.md#module-http2py.constants)             | Content-type strings shared across the request and response machinery.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| [`decorators`](http2py.decorators.html.md#module-http2py.decorators)           | Response handling: map http status codes to exceptions, decode the payload.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| [`default_configs`](http2py.default_configs.html.md#module-http2py.default_configs) | Default output transformations used when a method spec does not supply one.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| [`example_cli`](http2py.example_cli.html.md#module-http2py.example_cli)         | A tiny worked example of the CLI-making tools, used by the docs and by hand.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| [`global_state`](http2py.global_state.html.md#module-http2py.global_state)       | Process-wide state (notably the shared `requests` session) for the clients.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| [`http2py_cls`](http2py.http2py_cls.html.md#module-http2py.http2py_cls)         | (Http) Requests for humans                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| [`py2request`](http2py.py2request.html.md#module-http2py.py2request)           | Won't show the details here, but if you are used to it's not that hard, you just need to find the definition of the API, read it, figure out what part of the request you need in the URL and what you need to put in the "payload", figure out how those \_inputs_ of the request need to be formated, construct the URL and the payload according to your newly acquired knowledge of this specific API, make a web request (say with `urllib.request` or `requests`), extract the information you need from the response object (often in `.contents` or `.json()`), and often process the data further to get it in the format you can use it directly (say a list, a dict, a dataframe, a numpy array, etc.). |
| [`testing_utils`](http2py.testing_utils.html.md#module-http2py.testing_utils)     | Helpers for testing code that talks to an http service.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| [`util`](http2py.util.html.md#module-http2py.util)                       | Small general-purpose helpers: data files, dict defaults, JSON-ability checks.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
